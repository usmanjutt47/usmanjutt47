# 👨‍💻 About Me

I'm **Muhammad Usman Tariq**, a **Mobile Engineer, Full Stack Developer and Product Builder** focused on building polished, scalable and production-ready digital products.

My strongest area is **mobile development with React Native & Expo**, backed by full-stack development experience and growing Apple ecosystem expertise with **Swift & SwiftUI**.

I enjoy working across the complete product lifecycle — from interface implementation and application architecture to backend APIs, performance optimization and production deployment.

### What I work on

- 📱 Cross-platform mobile applications with **React Native & Expo**
- 🧭 Navigation architecture using **Expo Router**
- 🍎 Native Apple development with **Swift & SwiftUI**
- ⚡ APIs and backend systems with **Node.js & Express**
- 🌐 Modern web applications with **React & Next.js**
- 🗄️ Database-driven products with **MongoDB**
- 🔌 Third-party APIs and native integrations
- 🎨 Responsive and pixel-focused interfaces
- 🚀 Production deployment and application releases
- 📦 Open-source tools and reusable developer packages

> **I care about what happens between a design file and a production release.**
